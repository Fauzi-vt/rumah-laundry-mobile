# Rumah Laundry Mobile App

Aplikasi mobile-first untuk pemesanan dan pelacakan layanan laundry secara online. Dibuat menggunakan framework Flutter dengan arsitektur bersih dan reaktif berbasis Provider.

## Manual Book & Panduan Lengkap
Dokumentasi lengkap mengenai fitur, arsitektur kode, cara instalasi, konfigurasi jaringan/API, hingga penanganan masalah dapat dibaca di:
👉 **[MANUAL_BOOK.md](file:///d:/rumah_laundry_mobile/MANUAL_BOOK.md)**

## Cara Menjalankan Projek
1. Pastikan Flutter SDK telah terinstal (`v3.11.4` atau lebih baru).
2. Jalankan perintah untuk mengunduh semua dependency:
   ```bash
   flutter pub get
   ```
3. Sesuaikan alamat IP backend pada [api_constants.dart](file:///d:/rumah_laundry_mobile/lib/core/api_constants.dart).
4. Jalankan aplikasi menggunakan perintah:
   ```bash
   flutter run
   ```
